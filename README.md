# Basic-demo-repo-TCS-3rdNov

Open `index.html` in a modern browser to use **Daylight**, a responsive weather
dashboard. No installation, build step, or API key is required.

Search for a city and choose a result, or use the location button (location
permission requires HTTPS or localhost). Switch between Celsius and Fahrenheit
with the controls in the header.

Current conditions, hourly outlooks, and seven-day forecasts are provided by
[Open-Meteo](https://open-meteo.com/); city search uses its GeoNames-powered
geocoding API. Internet access is required. The free API is intended for
non-commercial use and is subject to Open-Meteo's usage limits and terms.
